Roundtrips per POSIX operation — Linux guest baseline (PERF-01)

Produced on <strong>11 November 2026, 11:35 CET</strong> by:

python3 tests/qemu/run_share_check.py --protos 9p --workload 30 \
        --trace e5-9p-trace.log --workdir /tmp/pgw-e5-trace \
        --cache ~/.cache/passerelle

The workload runs in a minimal Linux guest booted by QEMU 8.2.2 with -fsdev local,...,security_model=mapped-xattr and -device virtio-9p-pci (the exact options qshare emits). It executes:

  • mount,
  • a read of a file written by the host before the boot,
  • a write of a file read back by the host after the boot,
  • **30 cycles** of: create+write, `ls -l` (stat), `cat` (read), `rm` (unlink),
  • one `df -h` on the mount.

QEMU recorded 1 643 events (v9fs_*), handed to pbench roundtrips. This is the <strong>reference baseline</strong> of spec 7.5 against which Passerelle's own numbers must be compared once measured on a QNX guest.
